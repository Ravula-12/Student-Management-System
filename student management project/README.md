# Student Management System

## Overview
The Student Management System is a web application built using Python and Flask. It helps users manage student records by allowing them to add, view, edit, and delete student information.
## Features
- Add new student records
- View all student records
- Edit existing student details
- Delete student records
- Simple and responsive user interface
## Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Installation
### Step 1: Clone or Download the Project
Download the project folder to your computer.
### Step 2: Install Flask
Open the terminal and run:
bash
pip install flask
### Step 3: Run the Application
bash
python App.py
### Step 4: Open in Browser
Visit:
http://127.0.0.1:5000/
## Usage
1. Open the application in your browser.
2. Click *Add Student* to add a new student.
3. View the list of students on the home page.
4. Click *Edit* to modify student details.
5. Click *Delete* to remove a student.
